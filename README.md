
My collection of custom items, weapons, projectiles, sprites, gameplay mechanics, and other assets created for Terraria using C# and tModLoader.

## Current Content

* Custom weapons and items
* Magic spellbooks
* Custom projectile behavior
* Original sprites and visual assets
* Crafting recipes
* Gameplay experiments

## Status

This project is currently under active development. Content, artwork and gameplay behavior may change as development continues.
